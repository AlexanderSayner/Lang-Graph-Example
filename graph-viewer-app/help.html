LangGraph Flow Builder Guide

This builder allows you to visually design conversational AI flows powered by LangGraph.

1. Core Concepts

LangGraph flows are State Machines. They don't just run linearly; they loop, branch, and remember context.

  • State: The memory of the graph (variables, history).
  • Nodes: The logic blocks (LLM calls or pauses).
  • Edges: The transitions between nodes.

2. Node Types

  • 🚀 Start: The entry point. Required. Only one allowed.
  • 🤖 Action: An LLM step. It processes input and updates state.
  • 👤 Human: Pauses execution to wait for user input.
  • 🛑 End: Stops the flow and returns the final result.

3. Routing & Conditions

To create a "Router" (a decision point):

  1. Drag an Action Node (e.g., intent_router).
  2. Connect it to multiple targets.
  3. Click the connection lines and add Conditions (e.g., intent == 'billing').
  4. The Action Node will automatically become a Router if it has conditional outputs.

4. Best Practices

  • Router Prompts: Instruct the LLM to output JSON that matches your edge conditions.
    Example Prompt: "Extract 'intent'. Output JSON like {'intent': 'billing'}."
  • Human Nodes: Always place a Human Node after asking a question. This ensures the graph pauses and waits for the user's answer before continuing.
  • Loops: Connect a node back to a previous Router to create a loop (e.g., "Ask for clarification -> Router").
